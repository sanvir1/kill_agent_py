# kill_agent_py

Программа, **Memory Monitor** — это монитор оперативной памяти для операционной системы Windows. Она работает в фоновом режиме и отслеживает использование RAM (объем свободной оперативной памяти). Программа может автоматически освобождать память при превышении заданного порога использования, закрывая указанные процессы.
---
**Программа помогает поддерживать стабильную работу компьютера с небольшим объемом оперативной памяти, автоматически закрывая тяжелые процессы при высоком использовании RAM.**

### 💡 Возможные варианты использования:
- Ускорение работы системы с низким объемом RAM.
- Предотвращение тормозов или зависаний при активном использовании ресурсоемких браузеров.
- Автоматизация контроля за потреблением памяти.
---
### 🔍 Основные функции программы:

#### 1. **Мониторинг использования оперативной памяти**
- Программа регулярно проверяет текущий уровень использования RAM.
- Интервал проверки настраивается пользователем (по умолчанию — каждые 3 секунды).

#### 2. **Автоматическое закрытие процессов при высокой нагрузке**
- Если использование памяти превышает установленный порог (по умолчанию — 95%), программа:
  - Меняет цвет иконки в трее на красный.
  - Закрывает заранее заданные процессы (например: `chrome.exe`, `msedge.exe`, `firefox.exe`).
  - Отправляет уведомление о том, какие процессы были закрыты.

#### 3. **Ручное освобождение памяти**
- Пользователь может вручную запустить очистку памяти через контекстное меню трея.

#### 4. **Настройка параметров через графический интерфейс**
- Доступны следующие настройки:
  - Интервал проверки памяти (в секундах, от 1 до 60).
  - Порог использования памяти (в процентах, от 50 до 100).
  - Список процессов, которые будут закрываться при переполнении порога.
  - Автозапуск программы вместе с системой.

#### 5. **Интеграция с системным треем**
- Программа работает в трее (рядом с часами в правом нижнем углу экрана).
- Имеет контекстное меню:
  - Настройки
  - Освободить память сейчас
  - Выход

#### 6. **Поддержка автозапуска**
- Через реестр Windows (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`) можно включить/отключить автозапуск программы.

#### 7. **Сохранение настроек в конфигурационный файл**
- Все настройки сохраняются в файл `config.ini`.
- При повторном запуске программа восстанавливает предыдущую конфигурацию.
---

### 🛠️ Технологии и библиотеки:
- `psutil` — для получения информации о системе и управлении процессами.
- `tkinter` — для создания окна настроек.
- `pystray` — для работы с иконкой в системном трее.
- `PIL` (Pillow) — для генерации иконок.
- `winreg` — для настройки автозапуска в Windows.
- `configparser` — для работы с файлом настроек `config.ini`.
